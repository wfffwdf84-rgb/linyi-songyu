# Rules · 行为规则

## 语言

- 与用户对话**全部使用中文**。
- 站点产出物（HTML、Meta、广告文案）按目标市场语言；设计说明与日志用中文。

## 表达

- **零废话**：不写寒暄、不重复已知信息、不堆砌形容词。
- 一条信息只说一次；能列表就不段落。
- 结论前置；细节按需展开。

## 创作流程

1. 读取 `.cursor/MEMORY.md` 与 `.cursor/memory/work-log.md`。
2. 确认任务类型：设计 / SEO / SEM。
3. 读取 `industrial_trust_efficiency/DESIGN.md`（设计类任务必做）。
4. 执行并输出。
5. 更新工作日志。

## 设计规范

- 遵循 Industrial Trust & Efficiency 设计系统。
- 主色 `#7c5800`，强调 `#ffb800`，背景 `#f9f9fc`。
- 字体：Inter（UI/正文），IBM Plex Sans（标签/零件号/表格）。
- 圆角 0.25rem；桌面 12 列网格，最大宽 1280px。
- 组件：高对比按钮、信任徽章、零件号优先的产品卡、OEM 搜索。

## 输出标准

| 任务 | 必含内容 |
|------|----------|
| 页面设计 | 结构说明 + Tailwind HTML 或组件清单 |
| SEO | Title/Meta、H 层级、URL、Schema、内链建议 |
| SEM | 广告组、关键词、文案、落地页匹配、UTM |

## 禁止

- 不偏离品牌色与 DESIGN.md 规范。
- 不编造库存、认证、交期等未确认的业务数据。
- 不输出与任务无关的科普或延伸建议。
- 不未经请求创建 git commit 或推送。

## 文件约定

- Agent 配置：`.cursor/SOUL.md`、`.cursor/RULES.md`、`.cursor/MEMORY.md`、`.cursor/SKILLS.md`
- 技能：`.cursor/skills/b2b-designer/`、`.cursor/skills/b2b-seo/`、`.cursor/skills/b2b-sem/`
- 工作日志：`.cursor/memory/work-log.md`
